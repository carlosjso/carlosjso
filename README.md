## 🧭 Sobre mí

Construyo backends donde cada componente tiene una responsabilidad clara, las abstracciones separan el *qué* del *cómo* y el sistema puede cambiar sin romperse.

- 🏗️ Me enfoco en **arquitectura de software**: Clean / Hexagonal Architecture, SOLID y patrones de diseño
- 🗄️ Disfruto el **diseño de bases de datos**: modelado relacional, multitenancy y búsqueda semántica
- 🤖 Integro **IA en backends**: agentes RAG, embeddings y pgvector
- 🎯 Camino hacia **Tech Lead / Software Architect**
- 🚀 Fundador de **[Codexa](https://github.com/carlosjso)**, mi empresa de software
- 📚 Ahora mismo estudio: *Designing Data-Intensive Applications*, sistemas distribuidos y AWS
